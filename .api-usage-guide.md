## 🔑 Autenticación

Todos los endpoints requieren un token JWT válido en el header:

```http
Authorization: Bearer <tu_token_jwt>
```

El token contiene:
- `sub`: ID del usuario autenticado
- `email`: Email del usuario

## 💰 Cuentas (Accounts)

### 1. Crear Cuenta

**Endpoint:** `POST /accounts/create`

**Descripción:** Crea una nueva cuenta para el usuario autenticado.

**Headers:**
```http
Authorization: Bearer <token>
Content-Type: application/json
```

**Body:**
```json
{
  "name": "Cuenta de Ahorros",
  "currency": "USD",
  "balance": 1000.50,
  "icon": "💰"
}
```

**Respuesta Exitosa (201):**
```json
{
  "id": "uuid-generado",
  "name": "Cuenta de Ahorros",
  "currency": "USD",
  "balance": 1000.50,
  "icon": "💰",
  "user_id": "tu-user-id",
  "created_at": "2025-11-24T22:00:00Z",
  "updated_at": "2025-11-24T22:00:00Z"
}
```

**Notas de Seguridad:**
- ✅ El `user_id` se toma automáticamente del token JWT
- ❌ NO puedes crear cuentas para otros usuarios
- ✅ El `user_id` en la respuesta siempre será el tuyo

---

### 2. Actualizar Cuenta

**Endpoint:** `PUT /accounts/:account_id`

**Descripción:** Actualiza una cuenta existente (solo si eres el dueño).

**Headers:**
```http
Authorization: Bearer <token>
Content-Type: application/json
```

**Parámetros de Ruta:**
- `account_id`: ID de la cuenta a actualizar

**Body:**
```json
{
  "name": "Cuenta de Ahorros Premium",
  "currency": "EUR",
  "balance": 2000.00
}
```

**Respuesta Exitosa (200):**
```json
{
  "id": "account-id",
  "name": "Cuenta de Ahorros Premium",
  "currency": "EUR",
  "balance": 2000.00,
  "user_id": "tu-user-id",
  "updated_at": "2025-11-24T22:05:00Z"
}
```

**Errores Posibles:**
- `404 Not Found`: La cuenta no existe
- `403 Forbidden`: La cuenta no te pertenece

**Ejemplo de Error (403):**
```json
{
  "statusCode": 403,
  "message": "No tienes permiso para modificar esta cuenta"
}
```

**Notas de Seguridad:**
- ✅ Solo puedes actualizar tus propias cuentas
- ✅ El sistema valida que `account.user_id === tu_user_id`
- ❌ Intentar actualizar una cuenta ajena resulta en error 403

---

### 3. Obtener Todas las Cuentas

**Endpoint:** `GET /accounts/get/all`

**Descripción:** Obtiene todas las cuentas del usuario autenticado.

**Headers:**
```http
Authorization: Bearer <token>
```

**Respuesta Exitosa (200):**
```json
{
  "data": [
    {
      "id": "account-1",
      "name": "Cuenta de Ahorros",
      "currency": "USD",
      "balance": 1000.50,
      "user_id": "tu-user-id",
      "created_at": "2025-11-24T22:00:00Z"
    },
    {
      "id": "account-2",
      "name": "Cuenta Corriente",
      "currency": "EUR",
      "balance": 500.00,
      "user_id": "tu-user-id",
      "created_at": "2025-11-24T22:01:00Z"
    }
  ],
  "nextCursor": "account-id-de-la-ultima-cuenta"
}
```

**Notas de Seguridad:**
- ✅ Solo ves tus propias cuentas
- ✅ El `user_id` del token se usa automáticamente
- ❌ No puedes ver cuentas de otros usuarios

## 💸 Transacciones (Transactions)

### 1. Crear Transacción

**Endpoint:** `POST /transactions/save`

**Descripción:** Crea una nueva transacción en una de tus cuentas.

**Headers:**
```http
Authorization: Bearer <token>
Content-Type: application/json
```

**Body:**
```json
{
  "name": "Compra en supermercado",
  "amount": 50.75,
  "type": "expense",
  "account_id": "tu-account-id"
}
```

**Tipos de Transacción:**
- `saving`: Incrementa el balance
- `expense`: Decrementa el balance

**Respuesta Exitosa (201):**
```json
{
  "id": "transaction-id",
  "name": "Compra en supermercado",
  "amount": 50.75,
  "type": "expense",
  "account_id": "tu-account-id",
  "issued_at": "2025-11-24T22:10:00Z"
}
```

**Errores Posibles:**
- `404 Not Found`: La cuenta no existe
- `403 Forbidden`: La cuenta no te pertenece

**Ejemplo de Error (403):**
```json
{
  "statusCode": 403,
  "message": "No tienes permiso para crear transacciones en esta cuenta"
}
```

**Notas de Seguridad:**
- ✅ Solo puedes crear transacciones en tus propias cuentas
- ✅ El sistema valida que `account.user_id === tu_user_id`
- ❌ Intentar crear transacciones en cuentas ajenas resulta en error 403
- ⚠️ El balance de la cuenta se actualiza automáticamente

**Ejemplo de Actualización de Balance:**
```
Balance inicial: 1000.00
Transacción (expense): -50.75
Balance final: 949.25
```

---

### 2. Obtener Historial de Transacciones

**Endpoint:** `GET /transactions/history`

**Descripción:** Obtiene el historial de transacciones del usuario autenticado.

**Headers:**
```http
Authorization: Bearer <token>
```

**Query Parameters (opcionales):**
- `cursor`: ID de la última transacción de la página anterior (vacío en la primera petición)
- `take`: Número de registros a obtener (default: 10)
- `account_id`: Filtrar por cuenta específica (opcional)
- `types`: Tipos de transacciones separados por comas (ej: `saving,expense`)
- `startDate` / `endDate`: Rango de fechas en formato ISO-8601 (opcional)

**Ejemplos de Uso:**

#### Todas las transacciones del usuario (paginado)
```http
GET /transactions/history?take=10
```

#### Transacciones de una cuenta específica
```http
GET /transactions/history?account_id=tu-account-id&take=20
```

#### Siguiente página
```http
GET /transactions/history?cursor=transaction-id&take=10
```

**Respuesta Exitosa (200):**
```json
{
  "data": [
    {
      "id": "tx-1",
      "name": "Salario",
      "amount": 3000.00,
      "type": "saving",
      "account_id": "account-1",
      "issued_at": "2025-11-24T22:00:00Z"
    },
    {
      "id": "tx-2",
      "name": "Compra en supermercado",
      "amount": 50.75,
      "type": "expense",
      "account_id": "account-1",
      "issued_at": "2025-11-24T22:10:00Z"
    }
  ],
  "nextCursor": "tx-2"
}
```

**Notas de Seguridad:**
- ✅ Solo ves transacciones de tus propias cuentas
- ✅ Si especificas `account_id`, el sistema valida que sea tuya
- ✅ Las transacciones se ordenan por fecha (más recientes primero)
- ❌ No puedes ver transacciones de otros usuarios

## ⚠️ Códigos de Error

### 401 Unauthorized
**Causa:** Token JWT inválido o expirado

**Solución:** Renovar el token de autenticación

```json
{
  "statusCode": 401,
  "message": "No estás autenticado"
}
```

---

### 403 Forbidden
**Causa:** Intentando acceder a recursos que no te pertenecen

**Solución:** Solo accede a tus propios recursos

```json
{
  "statusCode": 403,
  "message": "No tienes permiso para acceder a esta cuenta"
}
```

---

### 404 Not Found
**Causa:** El recurso solicitado no existe

**Solución:** Verifica que el ID sea correcto

```json
{
  "statusCode": 404,
  "message": "Cuenta no encontrada"
}
```

---

### 400 Bad Request
**Causa:** Datos inválidos en el request

**Solución:** Verifica que los datos cumplan con las validaciones

```json
{
  "statusCode": 400,
  "message": [
    "name must be longer than or equal to 3 characters",
    "balance must be a positive number"
  ]
}
```

## 🧪 Ejemplos con cURL

### Crear Cuenta
```bash
curl -X POST http://localhost:3000/accounts/create \
  -H "Authorization: Bearer tu_token_jwt" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Mi Cuenta",
    "currency": "USD",
    "balance": 1000,
    "icon": "💰"
  }'
```

### Actualizar Cuenta
```bash
curl -X PUT http://localhost:3000/accounts/account-id \
  -H "Authorization: Bearer tu_token_jwt" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Cuenta Actualizada",
    "currency": "EUR",
    "balance": 2000
  }'
```

### Obtener Cuentas
```bash
curl -X GET http://localhost:3000/accounts/get/all \
  -H "Authorization: Bearer tu_token_jwt"
```

### Crear Transacción
```bash
curl -X POST http://localhost:3000/transactions/save \
  -H "Authorization: Bearer tu_token_jwt" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Compra",
    "amount": 50.75,
    "type": "expense",
    "account_id": "tu-account-id"
  }'
```

### Obtener Historial
```bash
curl -X GET "http://localhost:3000/transactions/history?take=10" \
  -H "Authorization: Bearer tu_token_jwt"
```

## 🔒 Mejores Prácticas de Seguridad

1. **Nunca compartas tu token JWT**
   - El token da acceso completo a tu cuenta

2. **Valida siempre las respuestas**
   - Verifica los códigos de estado HTTP
   - Maneja errores apropiadamente

3. **No intentes acceder a recursos ajenos**
   - El sistema bloqueará estos intentos
   - Podrían quedar registrados en logs de auditoría

4. **Usa HTTPS en producción**
   - Nunca envíes tokens por HTTP sin cifrar

5. **Renueva tokens regularmente**
   - Los tokens expiran en 5 días
   - Implementa refresh token si es necesario
